# 入学必备720字 - V4代码包（完整数据 + 拼音格/田字格/楷体 + 年级解锁 + 配图脚本）

## 这一版做了什么

### 1. 数据修正 + 全部720字组词/例句已完成
- 你要求的两处修正已生效：原本重复的"战舞闹斗"行，其中一次改成了"鸡鸭鹅燕"；
  "霜露電雾"里的繁体"電"改成了"雹"
- **720个字全部配齐了3个常用组词 + 1个例句**（不再是只有10个示例字）
- 拼音、笔顺、部首仍然来自上一版接入的cnchar词典库（真实校验数据）；
  组词/例句用cnchar对整句取拼音（比逐字拼接更能处理多音字，比如"长大"会读
  对zhǎng而不是cháng）
- 数据文件 `assets/data/hanzi_data.json` 从原来的几十KB涨到了612KB，
  属于正常范围，不会对App体积造成压力

### 2. 拼音"四线三格" + 汉字"田字格" + 楷体字
- 新增 `lib/widgets/pinyin_grid_text.dart`：拼音按传统的四线三格格式显示，
  基准线对齐书写主线
- 新增 `lib/widgets/tian_zi_ge_box.dart`：汉字显示在带十字虚线的方形格子里，
  字体用的是真正打包进App的楷体（不是寄希望于手机系统自带）
- **字体来源**：开源字体 [LXGW WenKai](https://github.com/lxgw/LxgwWenKai)
  （SIL Open Font License 1.1，可商用），原始文件25MB，
  用`fonttools`做了**字符子集化**——只保留这720个字实际用到的字形，
  砍到了**288KB**（缩小了约90倍），已验证720字全部覆盖、无缺字
- 协议要求保留版权声明，已经把 `OFL.txt` 一并放进了 `assets/fonts/` 目录，
  正式发布时不要删除这个文件

⚠️ 实现说明：四线三格目前是"整体居中+基准线对齐"的简化实现，不是逐字母
精确计算升部/降部位置，对拼音学习场景已经够用，但不是像素级精确对齐。

### 3. 默认首页改为"选择学习年级"
- `main.dart` 简化了，App打开后**始终**先看到年级选择页，不会再自动跳回上次
  学习的年级

### 4. 年级解锁机制 + 学习进度显示
- 新增 `lib/services/progress_service.dart`：统一管理"哪些年级已解锁"的逻辑
- 规则：**第1年级始终解锁**；某年级"学完"（该年级120个字全部浏览过一次）
  之后，才解锁下一年级；没学完，后面年级全部锁住
- 年级选择页每个年级卡片显示：进度条 + "已学X/120字"，锁住的年级显示锁图标，
  点击会弹出提示"请先学完xx年级才能解锁"
- "全部年级连续学"这个入口我做了调整：**改成只包含当前已解锁的年级**，
  不再是不受限制地访问全部720字——否则就变成了一个绕开解锁机制的后门，
  和你要的"必须循序解锁"的初衷是矛盾的
- "已学习"的判定标准是"浏览到过这个字"（滑动卡片经过它），存在本地，
  退出App再进来不会丢失进度

### 5. 配图批量生成脚本（Nano Banana）
新增 `scripts/generate_images_nanobanana.py`，调用Google Gemini API
（Nano Banana系列模型）批量生成720张配图。

**⚠️ 这个脚本需要你在自己电脑上运行**，原因：
1. 需要联网调用 `generativelanguage.googleapis.com`，这个域名不在
   当前沙盒环境的网络白名单里，我这边跑不通，只能帮你把脚本写好
2. 需要你自己的Gemini API Key（免费额度大约每天500次调用，
   见 https://aistudio.google.com/apikey）

脚本已经做了这些事，可以直接用，细节看脚本顶部的注释：
- **画面内容自动来源于例句**：比如"舌"这个字的画面描述会基于例句
  "小狗伸出了舌头"生成，而不是单纯画一个"舌头"，更接近教材插画的叙事感
- **风格统一**：固定的风格描述前后缀（手绘水彩、无文字、简洁背景），
  并支持传入一张参考图做风格锁定（`REFERENCE_IMAGE_PATH`配置项）
- **断点续跑**：已经生成过的字会自动跳过，网络中断重新运行不会重复花钱
- **自动接上WebP压缩流程**：生成的图自动裁切成正方形、压缩成WebP，
  按之前验证过的参数（400×400px, q80），并自动写回
  `hanzi_data.json` 里对应字的 `imageAsset` 字段

模型选择（脚本里改`MODEL_NAME`变量）：
| 模型 | 价格参考(2026年3月) | 适合 |
|---|---|---|
| `gemini-2.5-flash-image`（Nano Banana基础版，默认） | 约$0.039/张 | 预算优先，720张约$14~28 |
| `gemini-3-pro-image-preview`（Nano Banana Pro） | 约$0.134/张 | 风格一致性更好，720张约$96 |

运行方式：
```bash
pip install requests pillow
export GEMINI_API_KEY="你的key"
cd entrance_720_words
python3 scripts/generate_images_nanobanana.py
```

## 验证清单（这一版重点测试新增的UI和解锁逻辑）

1. App冷启动是否直接进入"选择学习年级"页（不是自动跳进某个年级）？
2. 一年级卡片是否显示"解锁"状态，二到六年级是否都显示锁图标？
3. 点击锁住的年级，是否弹出"请先学完xx年级"的提示，且没有跳转进去？
4. 进入一年级后，拼音是否显示在四线三格里？大字是否显示在带十字线的方格里、
   且是楷体字（明显区别于普通无衬线字体）？
5. 滑动浏览完一年级全部120个字后，返回年级选择页，一年级卡片是否显示
   "已学120/120"并打钩，二年级是否从锁住变成可点击？
6. 收藏、退出重进恢复进度等老功能是否依然正常？
7. 点击"已解锁年级连续学"，字数是否只等于已解锁年级的字数总和（不是720）？
8. 随便挑几个字（比如"鸡""雹""一""舌"），组词和例句是否都正常显示
   （不再是空白区块）？

## 接下来建议的优先级

1. **配图生成**：用上面的脚本批量跑一遍720张图（先用基础版Nano Banana试跑
   一小批，确认风格满意后再跑全部，避免风格不满意还要重新花钱生成）
2. 720字内容人工抽查一遍组词/例句的准确性和适龄性（机器辅助生成的内容
   建议过一遍人工审校，尤其是一些生僻字如"巳""芹""槐"等的组词选择）
3. 如果四线三格/田字格的视觉效果想要更精细（比如逐字母精确对齐升降部），
   需要更深入的字体度量计算，目前是简化实现

测试中遇到具体问题（界面跑偏、某个年级解锁逻辑不对等），把现象告诉我，我接着改。
